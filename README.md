# 道の駅とぎ海街道 多目的広場 3Dガイド

石川県志賀町「道の駅とぎ海街道 多目的広場」の配置・規模・利用案内を、3Dで確認できるページです。

- 公開ページ：`index.html`（このファイル1つで動作します）
- 外部への読み込み：なし（three.js r160 を同梱、フォントは端末の標準フォント）
- 管理：志賀町 商工観光課／（一社）志賀町観光協会
